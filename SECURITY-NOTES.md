# GitHub publication notes

This repository is a hackathon/demo project.

- Demo student identities and phone data have been replaced with clearly fictional placeholders.
- Do not add real student personal information.
- Do not commit `.env` files, Firebase Admin SDK/service-account JSON files, private keys, passwords, or access tokens.
- Firebase browser configuration may contain a client API key; review Firebase Authentication and Firestore security rules before production use.
- Any hard-coded OTP/payment behavior in the demo should be treated as a prototype only, not production authentication/payment security.
